# Group Project - Real-Time Chat Application

A real-time chat app with user registration/login (JWT + bcrypt) and live messaging via Socket.IO.

## Structure

- `client/` - Frontend (HTML, CSS, JavaScript), served statically by the server
- `server/` - Backend (Node.js, Express, Socket.IO, SQLite)
- `screenshots/` - Screenshots of the app

## Run

```bash
cd server
npm install
npm start
```

Open http://localhost:5000
